# 🚗 SmartPark - Parking Management System
**Sistem inteligent de gestiune a parcării dezvoltat în Java.**

### ✨ Funcționalități:
- **Interfață Grafică Modernă:** Componente custom cu gradiente și animații (Swing/AWT).
- **Drag & Drop:** Parcare intuitivă prin tragerea vehiculului pe locul dorit.
- **Validare Smart:** Motor de Regex pentru numere de înmatriculare din România (B vs Județe).
- **Persistență:** Salvare automată a stării parcării prin Serializare Java.
- **Facturare:** Generare automată de chitanțe în format text.

### 🛠️ Tehnologii & Concepte:
- **Design Patterns:** Strategy Pattern (pentru calculul taxelor).
- **Exception Handling:** Gestiune custom a erorilor de business.
- **File I/O:** Serializare obiecte și export fișiere .txt.
